Connect THIS Claude session to a running meta-orchestrator message hub (the Go hub a Pi brain starts with `/hub start`). Invoked `/hub-connect [hub-json-path] [name]` — the argument is the hub's discovery JSON path, defaulting to `$HOME/.meta-orch/hub.json` (what `/hub start` writes with no `--json`). It reads that JSON for the hub `url`, health-checks `/health`, registers this session as an agent (POST /register; an optional 2nd token is this worker's name — the address the brain `/send`s to — else one is generated), and confirms `connected to <url> as <name>`. It then lists the primitives for next steps (wait for an order `/next` which blocks, reply `/respond`, message a peer `/send` + `/await`) but does NOT loop on them — connecting is the whole job. Fails loud and STOPS if the JSON is missing/unreadable, has no `url`, `/health` doesn't answer (stale json / hub down), or `/register` is non-2xx — never fabricates a connection. The worker-side counterpart to the Pi-side `/hub start|status|stop`; the hub binary lives at `…/meta-orchestrator/hub/hub.go` and is spoken to over plain HTTP with curl.
