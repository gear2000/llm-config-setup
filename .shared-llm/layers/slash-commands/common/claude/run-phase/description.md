Run ONE phase of a plan with an explicit, caller-supplied agent roster. The worker playbook the meta-orchestrator brain launches per phase. Invoked `/run-phase plan=<path> phase=<N> agents=<a,b,...>`: reads the WHOLE plan file at `plan=`, finds Phase `<N>`, and executes that phase's work by dispatching EXACTLY the agents in `agents=` as subagents (the Task/Agent tool, one per agent, `subagent_type=<name>` verbatim — the brain already chose them; the worker never picks its own; an agent name that doesn't resolve fails loud). The worker IS the orchestrating lead AND the first-line plan check: it reads each subagent's return, checks it against the plan, and iterates dynamically toward the phase goal (re-dispatching as needed, not a rigid ralph loop). There is NO live watchdog (subagents don't run concurrently) — instead, after the work agents finish, the worker ALWAYS dispatches a mandatory `adversarial-evaluator` (a built-in gate on the strongest model, not part of `agents=`) that independently and adversarially reviews the finished phase against the plan; the phase passes ONLY if it returns CLEARED, otherwise the worker re-works the flagged piece and re-runs the gate, or escalates. The worker ends by emitting a machine-readable final verdict line — `PHASE_RESULT: passed|partial|blocked|failed` — that the brain records as the phase's true outcome (`passed` only when the work is fully done AND the evaluator CLEARED; never over a VEERED gate or incomplete work), so resume re-runs anything not truly passed. When it hits a decide-or-ask threshold (blocked, a leader's-call decision, a plan-changing discovery, or a VEERED it can't clear) it calls the injected `ask_brain` MCP tool to reach the resident leader and acts on the reply (continue, or STOP). Built to run INSIDE the `claude -p "/run-phase plan=… phase=… agents=…"` worker the meta-orchestrator Pi extension spawns — that spawned claude has the Task/Agent tool plus `ask_brain` injected; when `ask_brain` is absent (a bare by-hand run) it proceeds best-effort and notes it. Empty/missing args, a missing plan file, or a phase not found in the plan fail loud with a usage/why message.
