Run one phase of a canonical meta plan with a caller-supplied route profile. Invoked `/run-phase plan=<path> phase=<N> route=<route.yaml>`, it reads the plan and route profile, acts as the phase Lead Agent, resolves the phase lead and stage `llm_profile` + `agent` entries, runs the shared five-stage worktree protocol, and emits `PHASE_RESULT: passed|partial|blocked|failed`. Legacy global `agents=` rosters are not enough for the synchronized meta path; convert them into a route profile first. Stage agents and advisors are non-delegating, and the plan body stays routing-free. Stage 1/2 run on the temporary worktree branch, `merge_back_at` determines whether Stage 3, Stage 4, or Stage 5 merges to main, and Stage 5 finalizes with cleanup, green checks, and log review.
