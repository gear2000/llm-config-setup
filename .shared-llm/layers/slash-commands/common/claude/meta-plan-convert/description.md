Convert a loose Markdown plan into the meta runner two-file shape before semi-AFK execution. Invoked `/meta-plan-convert <source.md> <plan-output.md> [route-output.yaml]`, it preserves the plan intent, writes canonical `plan.md`, and writes `route.yaml` or `route.todo.yaml` with five stages, the temp-worktree branch template, Stage 3 default merge timing for non-interactive conversion, and TODOs instead of invented agents/profiles/checks.
