Convenience wrapper concept for Claude Code: run the normal `/cc-plan-and-grill` front-door planning flow, ask/record each phase's Stage 3/4/5 merge timing, then normalize/check the approved output into canonical meta-plan shape and pair it with a five-stage route profile (written to the path passed via `--route <route.yaml>`) for a later `/meta-cc` run. This does not rebrand `cc-*` as meta commands and does not change planning semantics.
