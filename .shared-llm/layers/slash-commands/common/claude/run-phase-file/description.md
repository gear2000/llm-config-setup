Run one phase of a canonical meta plan from files. Invoked `/run_phase --plan <plan.md> --phase <instructions.md> --route <route.yaml> --output <results.md>`, it reads the canonical plan, phase instructions, and resolved route profile, acts as the phase Lead Agent, runs the shared five-stage worktree protocol with non-delegating stage agents, and writes `results.md` whose leading `PHASE_RESULT:` line is the source of truth. The route profile supplies `llm_profiles` plus inline `agent` names; the plan body stays routing-free. Stage 1/2 run on the temporary worktree branch, `merge_back_at` determines the merge stage, and Stage 5 finalizes with cleanup, green checks, and log review. This command is hub-agnostic.
