Kick off a checked runnable `plan.md + route.yaml` pair through the Herdr-native meta runner. Requires `HERDR_ENV=1`. This is the TUI agent — the one pane you talk to. It gates the plan and route with the meta-plan check, sets up the run cockpit (`<slug>` workspace with a phase-leader, worker, and tui-agent pane) plus the always-up `shared-services` workspace (Recruiter + Librarian), then loops the plan's phases: it creates one phase leader per phase (running `/herdr-phase`) and destroys it after, reads each `phase-result.json`, and applies forward-only phase backtracking via `revisit:[phase-ids]` and the phase_pass_budget → advisor (optional) → human ladder, writing `run-status.md`. Every stage's work is done by a fresh worker hired through the Recruiter, never a native subagent. It stays small — decide re-run/continue, delegate hard evaluations to an advisor. Forward-only Ralph loop: no revert automation; a true revert stops and asks the human.
