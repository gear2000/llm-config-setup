Kick off a checked runnable `plan.md + route.yaml` pair through the Herdr-native meta runner. Requires `HERDR_ENV=1`. This is the TUI agent — the one pane you talk to. It gates the plan and route, sets up the cockpit plus shared services, then loops phases with one fresh phase leader each. Stage completion travels through durable Recruiter receipts; phase completion travels through the leader's event-driven marker plus authoritative `phase-result.json`, so no always-running LLM poller is needed. It applies forward-only backtracking and the configured advisor/human ladder, writing `run-status.md`. Every stage is done by a fresh Recruiter-hired worker. A true revert stops and asks the human.
