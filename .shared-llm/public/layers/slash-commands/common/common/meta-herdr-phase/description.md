Phase Lead Agent command for Meta-Herdr. Runs one canonical plan phase inside Herdr using a resolved route profile: validates the phase lead and stage `llm_profile` + `agent` entries, runs pre-flight dependency/import safety, then runs Stage 1 unit tests + implementation, Stage 2 adversarial audit, Stage 3 integration/acceptance seam testing, Stage 4 upstream DAG dependent verification, and Stage 5 finalization (merge if needed per `merge_back_at`, verify main, destroy temp worktree/branch, run green checks, inspect logs). Stage agents and advisors are non-delegating. Writes a phase result file with evidence; the file is the source of truth.
