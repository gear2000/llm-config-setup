Run a checked runnable `plan.md + route.yaml` pair through the Herdr-visible meta runner. Requires `HERDR_ENV=1`, a clean canonical plan, and a separate route profile with `llm_profiles` plus inline `agent` names for each phase lead and stage. Fails before creating panes if the runnable input check fails. It launches one phase Lead Agent pane at a time, and that lead runs the shared five-stage worktree protocol sequentially: Stage 1/2 on a temporary worktree branch, deterministic merge at Stage 3/4/5, and Stage 5 cleanup, green checks, and log review. No Claude team mode, no nested delegation.
