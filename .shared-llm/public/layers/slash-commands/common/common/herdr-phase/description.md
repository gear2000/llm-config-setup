Run one canonical plan phase as the Herdr-native phase leader, sent to a cockpit pane by `/herdr-run`. Requires `HERDR_ENV=1`. It validates the phase's route entry (lead, stages, `merge_back_at`, and `accuracy`, with `stage-0-alignment` present iff high), runs the pre-flight dependency/import safety check, then runs the phase's stages by placing one work ORDER per stage to the UpAgent Recruiter — a fresh hired worker each time, never a native or nested subagent. Each order also gets a tiny low-cost result watcher that polls only that order's `result_path`, so a valid `result.json` can wake the leader even if the Recruiter's pane-status wait sticks. It follows the shared five/six-stage worktree lifecycle (stage-0-alignment first when high, then implementation, adversarial audit including the unused-intake gate, integration/acceptance seams, upstream DAG verification, finalization), honoring the deterministic `merge_back_at` merge point and the Stage 2 independent-audit rule. It applies stage-level `revisit` backtracking (replay forward, increment try) and the stage_try_budget → advisor (optional) → give-up ladder, maintains `phase-status.md` (one line per stage per pass), and writes `phase-result.json` (verdict + `revisit:[phase-ids]`) as the source of truth. Forward-only: never reverts merged history — a true revert escalates to the TUI.
