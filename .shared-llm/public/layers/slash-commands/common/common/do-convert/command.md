# /do-convert

Pi conversion front door. It converts an approved big plan into a runnable Herdr run directory only when invoked with `--herdr`.

For Pattern 10 or Pattern 20 phase grading and YAML workflow assignments without phase leaders, use `/do-convert-pattern-10` or `/do-convert-pattern-20` instead. They prepare `workflow.yaml` without starting execution.

Use the shared conversion contract below with command name `do-convert`.
