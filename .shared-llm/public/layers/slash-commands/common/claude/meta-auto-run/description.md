The single kickoff workflow the Meta-ORCH brain sends to a freshly spawned Claude Code TUI session. Invoked `/meta-auto-run --plan <plan.md> --phase <instructions.md> --route <route.yaml> --output <results.md> --hub <loc>`, it runs `/hub-connect`, then `/run_phase` with the canonical plan plus route profile, then `/response`. The result file written by `/run_phase` is the source of truth; the hub ping is only an accelerator. The synchronized meta path uses a phase Lead Agent and non-delegating stage agents, follows the five-stage worktree lifecycle, and does not use Claude team mode.
