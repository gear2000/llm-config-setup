The full interactive build pipeline in ONE command. Chains, in a single session: research + plan + grill (via cc-plan-and-grill --route-phases) → freeze + convert to phase JSON (via rphase-create) → interactive phased implementation (via cc-loop --interactive). Heavy work runs in subagents (research, plan-writing, each phase's implementation); the grill and the per-phase verdicts run in the main thread because they need the user. This is a thin wrapper — a conductor: it invokes three existing skills in order and threads each one's output path into the next. It does NOT re-implement their logic. Use when you would otherwise run /cc-plan-and-grill, then /rphase-create, then /cc-loop --interactive by hand. Interactive only — never AFK. Because the plan and phases are frozen on disk, you can /clear at any point and resume with /cc-loop --interactive <phases_root>. Invocation: /cc-full <title>.
