# /cc-convert

Claude Code conversion front door. It converts an approved big plan into a runnable Herdr run directory only when invoked with `--herdr`.

Use the shared conversion contract below with command name `cc-convert`.

For Pattern 10 or Pattern 20 phase grading and YAML workflow assignments without phase leaders, use `/cc-convert-pattern-10` or `/cc-convert-pattern-20` instead. They prepare `workflow.yaml` without starting execution.
