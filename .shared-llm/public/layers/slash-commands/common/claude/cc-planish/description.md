Standalone lightweight Claude Code planner: grill the user on an annotatable HTML page, then produce and check a canonical `plan.md` + `route.yaml` pair before the explicit `herdr-run` handoff. The Claude Code port of the Pi /do-planish extension preserves the .planish.yaml contract, annotation-only feedback, and frozen plan-v<k> history. It does not implement work or start phases. Invocation: /cc-planish <topic>, /cc-planish --review <path>, optional --dir <path>.
