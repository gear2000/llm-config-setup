## Subagent usage

- Prefer the UpAgent Hub for delegated work because it provides cost control and visibility.
- Direct use of the harness's own subagents is acceptable, understandable, and typically permitted, especially with standard models such as Sonnet, Opus, and GPT-5.5.
- **NOTE:** Using the harness's own subagents for frontier models such as Fable 5.1 or ChatGPT 5.6 requires explicit user approval.
- The user will explicitly instruct the use of UpAgent workers for frontier models such as Fable 5.1 and ChatGPT 5.6. This counts as approved work.
