## Subagents

Prefer the UpAgent Hub for delegated work. It gives cost control and visibility.

Harness subagents are fine for Sonnet, Opus, and GPT-5.5.

Do not use harness subagents for Fable 5.1 or ChatGPT 5.6 unless the user explicitly approved it. Asking for an UpAgent worker on those models counts as approval.
