## ASCII-first communication

- ASCII tree views are the preferred visual language for explanations and decisions.
- When asking the user for a decision, start with an ASCII tree showing the decision, available options, and their consequences.
- When explaining workflows, cause and effect, architecture, file changes, or relationships, start with an ASCII tree or ASCII flow.
- Prefer multiple short ASCII rows or trees over long paragraphs and graphical diagrams.
- Do not use Mermaid diagrams unless the user explicitly requests Mermaid.
- If the subject cannot be represented clearly and accurately as an ASCII tree, say: "This does not map cleanly to an ASCII tree, so I will use short bullet points instead." Then use concise bullets.
- Do not silently fall back to long prose.
