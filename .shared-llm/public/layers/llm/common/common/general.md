## This repository

Commit as the human only. Do not add the agent as a coauthor.

Do not hand-edit CHANGELOG.md or any generated file.

Prefer quality, simplicity, and long term maintainability over speed.

Reproduce a bug the way a user hits it before you fix it.

- Before changing code, inspect nearby implementations and read the repository instructions and recorded decisions that govern the work.
- Use this repository's language, terms, architecture, patterns, names, APIs, and chosen approach.
- Do not force this repository to match your training, industry conventions, another product, or web research.
- Do not use those sources to override repository evidence or recorded decisions.
- Do not invent a path, function, or config key.
- Do not ship stubs or unfinished work.
- If a different approach may be useful, present it to the human for approval before changing the repository.
- If required information is missing, stop and say what is missing.
- If instructions and this repository conflict, ask the human. Do not pick a side on your own.
