# Third-party Pi extensions — pinned install manifest.
#
# One `pi install` source per non-comment line. Lines starting with `#` and
# blank lines are ignored. tools/install-pi-extensions.sh reads this file and
# runs `pi install <source>` for each line (skipping any already present in
# `pi list`), so any machine reproduces the exact set with one command.
#
# These are INSTALLED FROM SOURCE via `pi install` — never copied or vendored
# into this repo. (Our OWN authored extensions live in extensions/*.ts and are
# symlinked by setup-pi.sh; they are NOT listed here. See THIRD-PARTY-EXTENSIONS.md.)
#
# Pins: a fresh machine gets the pinned version written into settings.json's
# `packages` array. `pi install` matches by PACKAGE NAME, so on a machine that
# already has an entry (pinned or bare) it is a no-op and the existing entry is
# kept as-is — re-running never duplicates or downgrades. Bump a pin here, then
# `pi remove npm:<name>` + re-run the script to move a populated machine onto it.
