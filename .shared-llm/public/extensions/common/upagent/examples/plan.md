# Plan: sample two-phase build

Goal: demonstrate a medium phase and a high-accuracy phase end to end.

## Phase 0 — scaffold the module

Create the module skeleton and a passing smoke test.

Done:
- the module imports cleanly;
- the smoke test passes.

## Phase 1 — add the core feature

Implement the core feature against the scaffold.

Done:
- the feature works for the happy path;
- an adversarial audit clears.
