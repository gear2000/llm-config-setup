Your own T3 Code server, used from your phone

Each person gets their own always-on T3 Code server under their own login on the server. They sign in to the T3 Code phone app and control their coding agents from anywhere.

Let an agent do it

Give your agent (Claude Code, Codex, …) this request. It follows docs/T3-SETUP.md and stops when it needs you.

The whole flow

WHO runs each step · command · 🧑 only you can do this · ✓ check

T3 Code on your own login
│
├── 1. ADMIN on the server (sudo), once per person
│   ├── sudo useradd -m -s /bin/bash alice
│   └── sudo loginctl enable-linger alice
│       ✓ Linger=yes: the server starts at boot
│
├── 2. YOU on the server, logged in as alice
│   ├── git clone https://github.com/gear2000/llm-config-setup.git
│   ├── 🧑 claude auth login    (or codex login)
│   │      ✓ your own agent subscription
│   └── bash llm-config-setup/tools/t3-setup.sh
│       ├── installs T3, picks a port, starts the service
│       ├── 🧑 prints a link + code → open it → sign in or
│       │      create your T3 login → approve
│       └── ✓ All checks passed.
│
├── 3. YOU, optional: gh auth login   (GitHub for pull requests)
│
└── 4. 🧑 YOUR PHONE
    ├── install "T3 Code" (App Store or Google Play)
    ├── sign in with the same T3 login
    └── pick your server → start a thread
        ✓ the agent answers

Several people on one server

  • Each person repeats steps 1 to 4 with their own login and their own T3 login.
  • Give each person their own port and keep a list: t3-setup.sh --port 3774.
  • Threads, settings, tokens and agent logins stay in each person's own home folder. Other people cannot read them (home folders are mode 750 by default on Ubuntu).

Day to day

  • Check everything: bash llm-config-setup/tools/t3-setup.sh verify
  • Update T3: t3 update
  • Turn T3 Connect on again: t3 up --connect
  • Remove the service (keeps your threads): t3 service uninstall
