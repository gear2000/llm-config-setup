# Onboarding Checklist

Kit install and refresh: **[UPINSTALL.md](../UPINSTALL.md)**.

Adding a destination repository (file map, optional LLM-friendliness score, `this_repo/` stubs, nested `CLAUDE.md` / `AGENTS.md`): **[SETUP-DESTINATION.md](../SETUP-DESTINATION.md)**.

Dest-contextual UpAgent specialists (this-repo practice the hub can consult): **[SETUP-SPECIALISTS.md](../SETUP-SPECIALISTS.md)**.

Give those files to an LLM with `@UPINSTALL.md`, `@SETUP-DESTINATION.md`, or `@SETUP-SPECIALISTS.md`. The usual entry is `@UPINSTALL.md`.
